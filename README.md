# Valeo (valeo)

Valeo is a French global Tier 1 automotive supplier headquartered in Paris. Valeo designs and manufactures comfort and driving assistance, powertrain, thermal, and visibility systems for the automotive industry, with a strong focus on electrification and ADAS.
